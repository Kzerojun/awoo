### 📝 오늘의 주제: PWA 자체 푸시 알림과 manifest 파일에 대해

#### ✅ `manifest.json`이란?

PWA(Progressive Web App)를 만들기 위해 필수적으로 포함되는 JSON 형식의 메타 정보 파일이다.  
앱이 설치될 때 사용되는 **앱 이름, 아이콘, 시작 경로, 색상 등 UI/UX 관련 정보**를 정의한다.

```json
{
  "name": "AWOO Finance",
  "short_name": "AWOO",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#f9fafb",
  "icons": [
    {
      "src": "/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

#### 💬 manifest에서 중요한 속성들

| 속성명                | 설명                                                             |
| --------------------- | ---------------------------------------------------------------- |
| `name` / `short_name` | 앱 설치 후 홈 화면 및 앱 목록에 표시되는 이름                    |
| `start_url`           | 앱이 실행될 때 열리는 기본 경로                                  |
| `display`             | `standalone`, `fullscreen`, `minimal-ui`, `browser` 중 선택 가능 |
| `theme_color`         | 상단 상태바 등의 색상                                            |
| `icons`               | 앱 아이콘으로 사용될 이미지 목록                                 |

---

#### 🔔 PWA 자체 푸시 알림 개념 정리

> 푸시 알림은 `manifest.json`에 정의되지 않고, **서비스 워커(Service Worker)**에서 처리된다.
> 브라우저 또는 백엔드(Firebase 등)를 통해 **백그라운드에서 푸시를 수신하고** UI 알림을 생성한다.

```ts
// firebase-messaging-sw.js
self.addEventListener("push", function (event) {
  const data = event.data?.json() || {};
  self.registration.showNotification(data.title, {
    body: data.body,
    icon: "/icon-192.png",
  });
});
```

---

#### 🔧 연동 시 유의사항

- `manifest.json`은 앱 설치 및 초기 UX에 관여하지만, **푸시 알림은 완전히 별도의 경로**
- 푸시를 정상적으로 받기 위해선 브라우저 권한, FCM 토큰 발급, 서비스 워커 등록이 모두 필요
- `manifest` 없이도 푸시는 가능하지만, PWA UX를 갖추려면 `manifest + 서비스 워커`는 세트로 생각해야 함

---

#### 🛠️ 실제 작업 중 경험한 점

- 아이콘 이미지 경로가 잘못되면 앱 설치 시 아무런 이미지가 뜨지 않음 → 경로는 절대 경로 `/icon-XXX.png` 형태 추천
- iOS는 아직도 푸시 알림이나 PWA 지원이 완전하지 않아서 Android 중심 개발 필요
- manifest 변경사항이 바로 반영되지 않는 경우가 많음 → 브라우저 캐시 삭제 or DevTools → 'Clear storage'

---

#### ✍️ 느낀 점

> PWA에서 manifest는 단순히 앱 설치를 위한 파일이 아니라, **앱 자체의 정체성을 구성하는 중요한 요소**였다.
> 푸시 알림과 직접 연결되지는 않지만, 전반적인 UX 흐름에서 서로 긴밀히 연관되어 있다는 걸 체감했다.
> 푸시 기능은 서비스 워커, 권한 관리, 토큰 처리 등 기술적으로 복잡한 부분이 많다.
