### 📅 2025.03.18 (화) - 프론트엔드 디자인: 레이아웃 관련

프론트엔드에서 레이아웃은 디자인의 뼈대 역할을 하며, 초기 구조를 잘 잡는 것이 전체 개발 효율에 큰 영향을 준다.

#### ✅ 실무에서 유용한 레이아웃 설계 팁

1. **고정된 외곽 규격 먼저 정하자**

   - 예: `px-4 py-6`, `max-w-screen-xl`, `ml-64 mt-16` 등
   - 모든 페이지에 일관된 여백과 크기를 적용하면 유지보수가 쉬워짐

2. **반복되는 구조는 컴포넌트로 분리**

   - 레이아웃에 포함되는 Header, Sidebar, Footer는 별도 컴포넌트로 분리
   - 이후 페이지에서는 `Layout` 컴포넌트를 감싸는 방식으로 재사용

3. **`grid`와 `flex`를 구분해서 사용**

   - `flex`: 1차원 배치 (가로 or 세로 정렬)
   - `grid`: 2차원 배치 (가로 + 세로)
   - 복잡한 레이아웃은 `grid`가 더 직관적

4. **모바일 퍼스트 디자인 적용**

   - Tailwind 기준으로 `base → md → lg → xl` 순서로 스타일링
   - 작은 화면부터 설계한 후, 화면이 커질수록 점진적으로 레이아웃을 확장

5. **레이아웃 설계 시 와이어프레임 또는 스케치 참고**
   - 막히면 Figma, Dribbble, 또는 기존 프로젝트의 패턴을 참고

#### 🧩 예시 구조 (Tailwind + React 기준)

```tsx
<Layout>
  <Header />
  <main className="ml-64 mt-16 p-4">
    <Outlet />
  </main>
</Layout>
```

> 레이아웃은 “디자인보다 설계”라는 마인드로 접근하면 구조가 명확해진다.
