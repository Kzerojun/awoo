### 📅 2025.03.17 (월) - Yarn

**Yarn**은 JavaScript 패키지 매니저로, `npm`의 대안으로 자주 사용된다.

#### 📌 특징

- **빠른 설치 속도**: 병렬 다운로드 방식으로 `npm`보다 빠르다.
- **고정된 버전 관리**: `yarn.lock` 파일을 통해 패키지 버전을 일관되게 유지할 수 있다.
- **명령어 구성**이 직관적이고 깔끔하다.

#### 🛠️ 주요 명령어

```bash
yarn init                # 프로젝트 초기화
yarn add [패키지명]      # 패키지 설치
yarn remove [패키지명]   # 패키지 삭제
yarn install             # 모든 의존성 설치
```

#### ✅ 참고 사항

- `package-lock.json` 대신 `yarn.lock`이 생성된다.
- `npm`으로 설치한 프로젝트를 `yarn`으로 관리하려면 lock 파일을 제거하고 `yarn install`을 실행해야 한다.
