### 📅 2025.03.20 (목) - 코드 협업 툴 Gerrit

**Gerrit**은 Git 기반의 코드 리뷰 및 협업 툴로, 대규모 프로젝트에서 효율적인 코드 검토를 지원한다.

#### 🔹 Gerrit의 주요 특징

1. **Git 저장소와 연동** → 코드 변경 사항을 `push`하면 자동으로 리뷰 요청 생성
2. **Patchset 기반 리뷰** → 하나의 변경 사항을 여러 단계로 검토 가능
3. **Merge 전 코드 검증** → 변경 사항이 승인되기 전까지 `master`에 병합되지 않음
4. **CI/CD와 통합 가능** → Jenkins, GitLab CI와 연동하여 코드 품질 관리 가능

#### 🛠️ 기본 사용법

1. **Gerrit 서버에서 프로젝트 클론**
   ```bash
   git clone ssh://gerrit.example.com:29418/my-project
   cd my-project
   ```
2. **새로운 변경 사항 생성**
   ```bash
   git checkout -b feature/new-feature
   ```
3. **코드 수정 후 커밋**
   ```bash
   git add .
   git commit -m "feat: 새로운 기능 추가"
   ```
4. **Gerrit에 변경 사항 업로드**
   ```bash
   git push origin HEAD:refs/for/main
   ```
   - `refs/for/main`을 사용하면 **리뷰 요청 상태**로 푸시됨.

#### ✅ 실무 팁

- **코드 리뷰는 작은 단위로** → 너무 큰 PR은 피드백이 어려움
- **Gerrit UI에서 직접 라인별 코멘트 가능** → 리뷰어와 명확한 의사소통 가능
- **자동화된 테스트와 함께 사용** → CI/CD와 연동하여 코드 품질 관리

> **GitHub, GitLab의 PR 방식과 다르게, 변경 사항이 바로 병합되지 않고 리뷰를 거쳐야 한다는 점이 큰 차이점이다.**
