### 📘 주요 TypeScript 개념 정리

#### 1. 유틸 함수 분리: `toggleSection(indexes: number[])`

```ts
const toggleSection = (indexes: number[]) => {
  const allChecked = indexes.every((i) => checkedList[i]);
  const updated = [...checkedList];
  indexes.forEach((i) => {
    updated[i] = !allChecked;
  });
  setCheckedList(updated);
};
```

**왜 이렇게 했는가?**

- 섹션 전체 항목을 한 번에 토글해야 하므로 개별 `toggleCheck` 대신 별도 함수 필요

**원리**

- `every`로 전체 체크 여부 판단 → 이후 `forEach`로 일괄 상태 수정
- 불변성 유지 + 함수 분리로 재사용성과 가독성 확보

#### 2. 조건부 렌더링을 활용한 스타일 제어

```tsx
<CheckCircleIcon
  className={`w-5 h-5 ${isChecked ? "text-aqua" : "text-gray-300"}`}
/>
```

**왜 이렇게 했는가?**

- 체크 상태에 따라 아이콘 색상을 다르게 보여주기 위함

**실무 팁**

- Tailwind에서 `bg-${변수}`와 같은 동적 class는 purge 대상 → 문자열 조합은 피하고 `classnames` 사용 추천

---

#### 3. 유니언 타입 + 매핑 객체 활용

```ts
type ButtonSize = "short" | "medium" | "long";

const widthMap: Record<ButtonSize, string> = {
  short: "w-24",
  medium: "w-56",
  long: "w-72",
};
```

**왜 이렇게 했는가?**

- 공통 컴포넌트에서 props로 받는 값의 범위를 제한하고, 대응되는 클래스명을 지정하기 위해

**개념 원리**

- `Record<K, V>`는 K값들을 모두 key로 가지는 객체를 타입 안전하게 생성할 수 있게 함
- 유니언 타입 + `Record` 조합은 가장 안전한 매핑 방식 중 하나

#### 4. 조건부 비활성화 처리 (`disabled` + 색상 동기화)

```tsx
<Button
  text="다음"
  disabled={!checkedList.every(Boolean)}
  backgroundColor={checkedList.every(Boolean) ? "aqua" : "gray-300"}
/>
```

**주의할 점**

- `disabled` 속성 외에도 시각적으로 비활성 상태를 표현하는 class 동기화가 중요함  
  (`bg-color`, `cursor-not-allowed` 등)
