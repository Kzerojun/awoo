### 📘 주요 TypeScript 개념 정리

#### 1. `interface`를 통한 props 타입 정의

```ts
interface ProductSummaryProps {
  productName: string;
  description: string;
}
```

**왜 이렇게 했는가?**

- 컴포넌트를 재사용할 때, 전달받는 데이터 구조를 명확히 하고
- IDE 자동완성, 타입 추적, 리팩토링이 쉬워짐

**원리**

- TypeScript는 객체 구조의 타입을 명시할 수 있고, interface는 `extends` 등을 통해 확장이 쉬워서 props 정의에 자주 사용됨

---

#### 2. 선택적 프로퍼티(`?`)와 기본값 처리

```ts
interface ButtonProps {
  text?: string;
  size?: "small" | "medium" | "large";
}

const Button = ({ text = "확인", size = "medium" }: ButtonProps) => { ... }
```

**왜 이렇게 했는가?**

- 사용하는 쪽에서 props를 필수로 넘기지 않아도 되게끔 유연하게 처리
- 기본값 설정으로 일관성 유지

**실무 팁**

- 기본값이 있는 경우에는 `?` 붙이고, 내부에서 디폴트 처리하는 것이 유지보수에 유리함

---

#### 3. 유니언 타입으로 제한된 값만 받도록 구성

```ts
type ButtonSize = "small" | "medium" | "large";
```

**이점**

- 실수로 잘못된 값 입력 방지
- 자동완성 기능 향상
- 명확한 디자인 시스템 대응 가능
