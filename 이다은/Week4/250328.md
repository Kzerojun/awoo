## 💡 JavaScript 심화 - Execution Context, Event Loop, 비동기 처리

### ✅ Execution Context (실행 컨텍스트)

> 자바스크립트 코드가 실행될 때 생성되는 **실행 환경**

- 구성요소
  - VariableEnvironment
  - LexicalEnvironment (Scope)
  - thisBinding
- 특징
  - 코드가 실행되면 **실행 컨텍스트**가 생성되어 스택에 쌓임
  - 실행이 끝나면 스택에서 제거됨
  - 함수 호출마다 **새로운 컨텍스트**가 생성됨

```js
function foo() {
  console.log("foo");
}
foo();
```

- 위 코드에서 `foo()`를 호출하면 `foo` 함수의 **Execution Context**가 스택에 쌓였다가 함수 종료 후 제거

---

### ✅ Lexical Environment

- 스코프 체인 (Scope Chain) 이라고도 불림
- **상위 스코프의 환경 정보를 참조**하여 변수 탐색 가능
- 실행 컨텍스트 내부에서 `Lexical Environment`를 통해 변수 접근

```js
function outer() {
  let a = 1;
  function inner() {
    console.log(a); // outer의 LexicalEnvironment를 탐색
  }
  inner();
}
outer();
```

### ✅ Event Loop

> 자바스크립트가 싱글 스레드인데도 비동기 처리를 가능하게 해주는 핵심 메커니즘

- 구성
  - Call Stack
  - Event Queue (Task Queue)
  - Job Queue (Microtask Queue)
- 동작 순서
  1. Call Stack이 비어있을 때 Event Queue에서 작업을 가져와 실행
  2. Microtask Queue (ex. Promise.then) > Event Queue (ex. setTimeout)

---

```js
console.log("start");
setTimeout(() => console.log("setTimeout"), 0);
Promise.resolve().then(() => console.log("promise"));
console.log("end");

// 실행 결과:
// start
// end
// promise
// setTimeout
```

- `Promise.then`이 `setTimeout`보다 먼저 실행되는 이유  
  → **Microtask Queue**가 **Event Queue**보다 우선순위가 높기 때문

---

### ✅ 비동기 처리 패턴

| 패턴        | 설명                                              |
| ----------- | ------------------------------------------------- |
| Callback    | 콜백 지옥으로 가독성, 유지보수성 낮음             |
| Promise     | `then`, `catch`, `finally` 체이닝 가능            |
| async/await | 동기처럼 보이는 비동기 처리, 에러는 `try/catch`로 |

```js
async function fetchData() {
  try {
    const res = await fetch("/data");
    const json = await res.json();
    console.log(json);
  } catch (e) {
    console.error(e);
  }
}
```

---

### ✨ 오늘의 느낀점

- 단순히 Event Loop만 외우지 말고 **Task Queue**와 **Microtask Queue**를 구분해야 면접 때 실수하지 않을 것 같다.
- Execution Context는 실제로는 잘 못 느끼는 개념인데, JS 엔진 내부에서 중요한 흐름임을 알게 됐다.
- 비동기 코드를 볼 때, Event Loop의 구조를 떠올려야 **비동기 실행 순서**를 실수하지 않을 것 같다.
