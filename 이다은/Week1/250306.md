# 250306 - Next.js, PWA, TypeScript 실습 및 핀테크 조사 🚀

## 🔍 오늘 배운 내용

### 1. Next.js란?

- **React 기반의 프레임워크**로, 서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG)을 지원.
- **파일 기반 라우팅:** `pages` 폴더에 파일을 생성하면 자동으로 라우팅 처리.
- **장점:**
  - **SEO에 강함:** 서버에서 렌더링된 HTML 제공.
  - **빠른 빌드:** 정적 파일 생성 가능.
  - **API 라우트:** `api` 폴더를 통해 간단히 백엔드 API 구성 가능.

---

### 2. PWA (Progressive Web App)란? 📱

- **웹 기술로 네이티브 앱처럼 동작**하는 웹 애플리케이션.
- **주요 특징:**
  1. **오프라인 지원:** Service Worker로 네트워크가 끊겨도 사용 가능.
  2. **푸시 알림:** Web Push API를 통해 사용자에게 알림 전송.
  3. **앱 설치:** 홈 화면에 추가 가능 (`manifest.json` 필요).

---

### 3. TypeScript란? 🛠️

- **JavaScript의 상위 확장**으로, 정적 타입 검사 지원.
- **장점:**
  - **코드 안정성:** 타입 에러를 컴파일 시점에 미리 확인.
  - **개발 생산성:** 자동 완성과 리팩토링에 유리.
- **주요 문법:**

  ```tsx
  type User = {
    name: string;
    age: number;
    isActive: boolean;
  };

  const user: User = {
    name: "Daeun",
    age: 25,
    isActive: true,
  };
  ```

### 🛠️ 실습한 내용

#### 1. Next.js 프로젝트 생성

```bash
npx create-next-app@latest my-next-app -ts
```

- **-ts 옵션:** TypeScript 템플릿 사용.

---

#### 2. PWA 설정 (Next.js)

- **패키지 설치:**
  ```bash
  npm install next-pwa
  ```
- **`next.config.js` 설정:**

  ```js
  const withPWA = require("next-pwa")({
    dest: "public",
    disable: true,
  });

  module.exports = withPWA({
    reactStrictMode: true,
  });
  ```

- **Service Worker 등록:**
  `public/manifest.json`과 `public/sw.js` 작성.

---

#### 3. TypeScript 기본 설정

- **타입 설정 (`tsconfig.json`):**
  ```json
  {
    "compilerOptions": {
      "target": "esnext",
      "lib": ["dom", "dom.iterable", "esnext"],
      "allowJs": true,
      "skipLibCheck": true,
      "strict": true,
      "forceConsistentCasingInFileNames": true,
      "noEmit": true,
      "incremental": true,
      "module": "esnext",
      "moduleResolution": "node",
      "resolveJsonModule": true,
      "isolatedModules": true,
      "jsx": "preserve"
    },
    "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx"],
    "exclude": ["node_modules"]
  }
  ```
