# 250306- PWA에서 카메라 호출하기

## 🔥 **PWA에서 카메라를 호출하는 방법**

PWA(Progressive Web App)는 웹 기술을 활용해 네이티브 앱처럼 작동한다. 사진을 찍기 위해 PWA에서 카메라를 호출하는 방법에는 크게 두 가지가 있다.

---

### 📸 1. `<input>` 태그를 이용한 간단한 카메라 호출

HTML의 `<input>` 태그에 `capture` 속성을 추가해 간단하게 카메라를 호출할 수 있다.

```html
<input type="file" accept="image/*" capture="environment" />
```

#### 🔍 **코드 설명**

- **`accept="image/*"`**: 이미지 파일만 선택 가능하게 제한한다.
- **`capture="environment"`**: 후면 카메라를 호출한다. (전면 카메라는 `user` 사용)
- **장점**: 사용법이 매우 간단하며 대부분의 모바일 브라우저에서 지원한다.
- **단점**: 커스텀이 어렵고 제어가 제한적이다.

---

### 📹 2. MediaDevices API를 이용한 유연한 카메라 호출

JavaScript의 `navigator.mediaDevices.getUserMedia()`를 사용해 더 유연하게 카메라를 제어할 수 있다.

```html
<video id="camera" autoplay></video>
<button id="capture-btn">사진 찍기</button>
<canvas id="canvas" style="display: none;"></canvas>
<img id="photo" />

<script>
  const video = document.getElementById("camera");
  const canvas = document.getElementById("canvas");
  const photo = document.getElementById("photo");
  const captureBtn = document.getElementById("capture-btn");

  // 카메라 실행
  navigator.mediaDevices
    .getUserMedia({ video: true })
    .then((stream) => {
      video.srcObject = stream;
    })
    .catch((error) => {
      console.error("카메라 접근 불가:", error);
    });

  // 사진 찍기
  captureBtn.addEventListener("click", () => {
    const context = canvas.getContext("2d");
    canvas.width = video.videoWidth;
    canvas.height = video.videoHeight;
    context.drawImage(video, 0, 0, canvas.width, canvas.height);
    const imageData = canvas.toDataURL("image/png");
    photo.src = imageData; // 캡처된 사진 표시
  });
</script>
```

#### 🔍 **코드 설명**

- **`getUserMedia()`**: 사용자의 카메라 접근 권한을 요청하고, 비디오 스트림을 받아온다.
- **`drawImage()`**: `<canvas>`에 현재 비디오 프레임을 캡처해 그린다.
- **`toDataURL()`**: 캡처된 이미지를 URL 형식으로 변환해 `<img>`에 표시한다.
- **장점**: 커스텀 가능 (해상도, 전후면 카메라 전환, 필터 적용 등).
- **단점**: 코드가 다소 복잡하고 HTTPS 환경에서만 작동한다.

---

### 🛠 **PWA 호환성 체크: Service Worker 등록**

PWA에서 카메라 기능을 원활히 사용하려면 Service Worker 등록이 필요하다.

```js
if ("serviceWorker" in navigator) {
  navigator.serviceWorker
    .register("/service-worker.js")
    .then(() => console.log("Service Worker 등록 완료"))
    .catch((error) => console.log("Service Worker 등록 실패:", error));
}
```

#### 🔍 **설명**

- **HTTPS 환경 필수**: `getUserMedia()`는 보안된 HTTPS 환경에서만 동작한다.
- **오프라인 사용 가능**: Service Worker를 통해 오프라인에서도 PWA가 작동한다.

---

### ❓ **정리: 어떤 방법을 사용할까?**

| **구분**      | **간단한 방법 (`<input>`)**         | **유연한 방법 (MediaDevices API)**     |
| ------------- | ----------------------------------- | -------------------------------------- |
| **장점**      | 쉽고 빠르게 적용 가능               | 커스텀 및 다양한 기능 확장 가능        |
| **단점**      | 커스텀 어려움                       | 코드 복잡, HTTPS 필수                  |
| **사용 추천** | 기본적인 사진 촬영 기능만 필요할 때 | 해상도 조절 등 커스텀 기능이 필요할 때 |

---

### ✅ **오늘의 배움**

  1. `<input>` 태그를 이용한 간단한 방법
  2. `getUserMedia()`를 이용한 유연한 방법
- HTTPS 환경에서만 카메라 호출이 가능하다는 점을 인지했다.
- Service Worker를 통해 오프라인 지원이 필요하다.
