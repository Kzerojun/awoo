## 📆 2025.04.04 (금)

### 🧠 오늘의 주제: `useMemo`란 무엇인가?

#### ✅ 개념 정리

`useMemo`는 React에서 제공하는 Hook 중 하나로, 컴포넌트가 리렌더링될 때 **비용이 큰 연산을 매번 다시 계산하지 않도록** 캐싱하는 데 사용된다.  
`useEffect`와 다르게, `useMemo`는 값(value)을 기억하며, 의존성 배열(dependency array)에 있는 값이 변경될 때만 연산을 다시 수행한다.

```tsx
const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
```

위 예시에서 `a` 또는 `b`가 변경되지 않으면, `computeExpensiveValue`는 다시 실행되지 않고 이전 값을 그대로 반환한다.

---

#### 📌 사용 이유

- 무거운 계산 로직이 렌더링마다 실행되는 것을 방지
- 동일한 props가 전달되었을 때도 재계산되는 것을 막아 성능 최적화
- 자식 컴포넌트에 전달되는 객체, 배열, 함수의 **불필요한 재생성** 방지 → `React.memo`와 함께 쓰면 효과적

#### 💡 사용 예시

```tsx
const sortedList = useMemo(() => {
  return [...list].sort((a, b) => a.value - b.value);
}, [list]);
```

리스트 정렬처럼 연산이 복잡한 경우, `list`가 변경될 때만 정렬이 수행되도록 제한할 수 있다.

또는, 객체 형태의 필터 조건을 전달해야 할 때도 유용하다.

```tsx
const filterOptions = useMemo(
  () => ({ keyword, category }),
  [keyword, category]
);
```

이렇게 하면 `filterOptions`가 매번 새로 생성되지 않기 때문에 `React.memo` 컴포넌트가 불필요하게 리렌더링되지 않는다.

#### ✍️ 느낀 점

> “최적화를 위한 도구는 필요한 곳에만 써야 한다.”
> `useMemo`는 React의 성능 향상을 도와주는 강력한 도구이지만, **무분별하게 사용하면 오히려 성능을 해칠 수 있다.**
> 연산 비용이 높은 로직에만 적용하고, 그 외에는 불필요하게 사용하지 않도록 의도적으로 구분해서 사용하자.
