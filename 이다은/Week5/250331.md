## 💡 React 심화 - useMemo vs useEffect vs useCallback

### ✅ useMemo

> 값(연산 결과)을 **메모이제이션** 하는 훅

- **목적**

  - 복잡한 연산을 캐싱하여 불필요한 재계산 방지

- **특징**
  - 의존성 배열(deps)의 값이 바뀔 때만 콜백을 실행하여 **계산된 값을 반환**
  - 렌더링마다 재실행되는 것을 막아 성능 최적화

```js
const expensiveValue = useMemo(() => heavyCalculation(a, b), [a, b]);
```

- **면접포인트**
  - `useMemo()`가 없는 경우: 매 렌더링마다 `heavyCalculation()`이 실행됨
  - 너무 자주 남발하면 오히려 **메모이제이션 비용**이 커질 수도 있음

---

### ✅ useEffect

> **부수효과(Side Effect)** 를 처리하는 훅

- **목적**
  - 렌더링 후 의존성 값이 변경될 때마다 콜백 실행
  - 주로 비동기 통신, 이벤트 등록/해제, DOM 조작 등에 사용

```js
useEffect(() => {
  window.addEventListener("resize", onResize);
  return () => window.removeEventListener("resize", onResize);
}, []);
```

- **면접포인트**
  - 의존성 배열이 없으면? → 모든 렌더링마다 실행됨
  - 의존성 배열이 비어있으면? → 최초 마운트 시 1번만 실행
  - cleanup 함수?  
    → 컴포넌트 언마운트 시, 혹은 deps 변경 시 이전 작업 정리 (메모리 누수 방지)

---

### ✅ useCallback

> **함수를 메모이제이션** 하는 훅

- **목적**
  - 함수 객체가 불필요하게 새로 만들어지는 것을 방지
  - `React.memo`로 감싼 하위 컴포넌트에 넘기는 콜백 함수의 재생성을 막음

```js
const handleClick = useCallback(() => {
  console.log("clicked");
}, []);
```

- **면접포인트**
  - `useMemo()`는 **값**을 메모이제이션
  - `useCallback()`은 **함수**를 메모이제이션
  - `useCallback(fn, deps)` === `useMemo(() => fn, deps)`

---

### ✅ 비교 정리

| 훅          | 목적               | 반환값    | 언제 사용?                               |
| ----------- | ------------------ | --------- | ---------------------------------------- |
| useMemo     | 값 메모이제이션    | 계산된 값 | 무거운 계산 결과 캐싱                    |
| useEffect   | 사이드 이펙트 처리 | 없음      | 렌더링 후 비동기, DOM조작, 이벤트        |
| useCallback | 함수 메모이제이션  | 함수      | 함수 재생성 방지, React.memo와 함께 사용 |
