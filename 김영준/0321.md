# @AttributeOverrides / @AttributeOverride
## @AttributeOverrides
여러 개의 속성 매핑을 한꺼번에 재정의할 때 사용합니다. 복수형(s)이라 여러 @AttributeOverride를 묶어주는 역할을 합니다.
한 엔티티안에 임베디드 객체가 있고, 그 객체의 속성을 기본 매핑과 다르게 설정하고 싶을때 사용합니다.
 
##@AttributeOverride
단일 속성의 매핑을 재정의합니다.

name : 재정의할 속성 이름 (임베디드 객체안의 필드이름)
column : 새로 지정할 데이터베이스 컬럼 정보(여기서는 @Column으로 정의)
@Column : 데이터베이스 테이블에서 속성이 매핑될 컬럼 이름 재정의
```
@Entity
public class Customer {
    @Id
    private Long id;
    private String name;

    @Embedded
    @AttributeOverrides({
        @AttributeOverride(name = "city", column = @Column(name = "home_city")),
        @AttributeOverride(name = "street", column = @Column(name = "home_street")),
        @AttributeOverride(name = "zipcode", column = @Column(name = "home_zipcode"))
    })
    private Address homeAddress;

    @Embedded
    @AttributeOverrides({
        @AttributeOverride(name = "city", column = @Column(name = "work_city")),
        @AttributeOverride(name = "street", column = @Column(name = "work_street")),
        @AttributeOverride(name = "zipcode", column = @Column(name = "work_zipcode"))
    })
    private Address workAddress;

    // 생성자, getter, setter 생략
}
```
