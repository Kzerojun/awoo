# Embeddable 과 Embedded
## @Embeddable
JPA에서 값 객체를 정의할 때 사용하는 어노테이션입니다. 값 객체란 고유한 식별자 ID가 없는 객체로, 주로 다른 엔티티의 속성을 보조하거나 특정한 의미를 가진 데이터의 집합입니다.

데이터 베이스에서 별도의 테이블로 생성되지 않습니다.
이 값 객체를 사용하는 엔티티의 테이블에 컬럼으로 매핑됩니다.
관련된 속성들을 하나의 객체로 묶어 사용하여 직관성을 높일 수 있습니다.

@Embedded
엔티티 클래스에서 @Embeddable로 정의된 값 객체를 실제로 사용하는 필드에 붙이는 어노테이션입니다.
값 객체의 속성을 엔티티 테이블에 통합하여 매핑하는 역할을 합니다.
```
@Embeddable
public class Address {
    private String city;
    private String street;
    private String zipcode;
 
 
   //생성자,Getter,Setter등등
}
@Entity
public class Customer {
    @Id
    private Long id;
    private String name;

    @Embedded
    private Address address;
    
  }
```
