JPA를 사용하다 보면 엔티티와 데이터베이스 테이블 간의 매핑을 유연하고 효율적으로 처리해야할 때 가 많습니다.
이때 Value Object와 Composite Key를 다루는데 핵심적인 역할을 하는 두 어노테이션 @Embeddable과 @Embedded가 있습니다.

## Embeddable 과 Embedded

@Embeddable
JPA에서 값 객체를 정의할 때 사용하는 어노테이션입니다. 값 객체란 고유한 식별자 ID가 없는 객체로, 주로 다른 엔티티의 속성을 보조하거나 특정한 의미를 가진 데이터의 집합입니다.

데이터 베이스에서 별도의 테이블로 생성되지 않습니다.
이 값 객체를 사용하는 엔티티의 테이블에 컬럼으로 매핑됩니다.
관련된 속성들을 하나의 객체로 묶어 사용하여 직관성을 높일 수 있습니다.
@Embedded
엔티티 클래스에서 @Embeddable로 정의된 값 객체를 실제로 사용하는 필드에 붙이는 어노테이션입니다.

값 객체의 속성을 엔티티 테이블에 통합하여 매핑하는 역할을 합니다.

 
```
@Embeddable
public class Address {
    private String city;
    private String street;
    private String zipcode;
 
 
   //생성자,Getter,Setter등등
}
@Entity
public class Customer {
    @Id
    private Long id;
    private String name;

    @Embedded
    private Address address;
    
  }
 
```
그런데 다음과 같은 상황을 상상해봅시다. 만약 Customer가 직장주소와 집주소 처럼 두개의 주소를 가진다면 컬럼이름의 중복을 피해야합니다. 이때 사용하는 어노테이션이 @AttributeOverrides를 사용해야합니다.

 

## @AttributeOverrides / @AttributeOverride
@AttributeOverrides
여러 개의 속성 매핑을 한꺼번에 재정의할 때 사용합니다. 복수형(s)이라 여러 @AttributeOverride를 묶어주는 역할을 합니다.
한 엔티티안에 임베디드 객체가 있고, 그 객체의 속성을 기본 매핑과 다르게 설정하고 싶을때 사용합니다.
 

@AttributeOverride
단일 속성의 매핑을 재정의합니다.

- name : 재정의할 속성 이름 (임베디드 객체안의 필드이름)
- column : 새로 지정할 데이터베이스 컬럼 정보(여기서는 @Column으로 정의)

```
@Column : 데이터베이스 테이블에서 속성이 매핑될 컬럼 이름 재정의
@Entity
public class Customer {
    @Id
    private Long id;
    private String name;

    @Embedded
    @AttributeOverrides({
        @AttributeOverride(name = "city", column = @Column(name = "home_city")),
        @AttributeOverride(name = "street", column = @Column(name = "home_street")),
        @AttributeOverride(name = "zipcode", column = @Column(name = "home_zipcode"))
    })
    private Address homeAddress;

    @Embedded
    @AttributeOverrides({
        @AttributeOverride(name = "city", column = @Column(name = "work_city")),
        @AttributeOverride(name = "street", column = @Column(name = "work_street")),
        @AttributeOverride(name = "zipcode", column = @Column(name = "work_zipcode"))
    })
    private Address workAddress;

    // 생성자, getter, setter 생략
}
```
