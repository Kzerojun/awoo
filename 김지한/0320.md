# @FeignClient

`@FeignClient`는 Spring Cloud에서 제공하는 어노테이션으로, HTTP 클라이언트를 쉽게 생성하고 다른 서비스와 RESTful API를 호출하는 데 사용됩니다. Feign은 선언적 웹 서비스 클라이언트를 구현하는 데 도움을 주며, RESTful 서비스와의 통신을 간편하게 처리할 수 있게 해줍니다.

## 사용법

`@FeignClient` 어노테이션은 주로 인터페이스에 적용하여 사용합니다. 이를 통해 외부 API를 호출하는 클라이언트 코드가 자동으로 생성됩니다.

## 기본 사용 예시

```java
@FeignClient(name = "my-service", url = "http://localhost:8080")
public interface MyServiceClient {

    @GetMapping("/api/resource")
    String getResource();
}
```

- name: 호출할 서비스의 이름을 지정합니다.

- url: API 서버의 기본 URL을 지정할 수 있습니다. (Eureka와 통합 시에는 필요하지 않음)


## 특징

- HTTP 요청 방식 자동 처리

    - @FeignClient는 HTTP 요청을 자동으로 처리하며, 메서드의 반환 타입에 맞는 응답을 반환합니다.

- RESTful API 호출

    - @GetMapping, @PostMapping, @PutMapping, @DeleteMapping과 같은 Spring의 HTTP 메서드 어노테이션을 사용하여, RESTful API 호출을 선언적으로 처리할 수 있습니다.

- Eureka 통합

    - name 속성으로 지정한 서비스 이름은 Eureka 서버에서 등록된 서비스와 매핑되어, 로드 밸런싱이 자동으로 처리됩니다.

- 디폴트 오류 처리

    - Feign 클라이언트는 기본적으로 오류 처리가 내장되어 있으며, 커스터마이징이 가능합니다.


## 예시: 파라미터와 헤더 추가

```java
@FeignClient(name = "pet" )
public interface PetClient {

    @GetMapping("/api/pets/{petId}")
    ApiUtils.ApiResult<?> getPetInfo(@PathVariable Integer petId);


    @GetMapping("/api/pets")
    ApiUtils.ApiResult<?> getPetList(@RequestHeader("X-User-Id") Integer memberId);

}
```

- @PathVariable: URL 경로 변수로 값을 전달합니다.

- @RequestBody: 요청 본문에 객체를 포함하여 전달합니다.

- @RequestParam: 쿼리 파라미터를 전달합니다.

## 의존성 추가


```java
    //Feign Client
    implementation 'org.springframework.cloud:spring-cloud-starter-openfeign'
```


## 활성화 방법


```java
  @SpringBootApplication
    @EnableFeignClients
    public class Application {
        public static void main(String[] args) {
            SpringApplication.run(Application.class, args);
        }
    }

```
