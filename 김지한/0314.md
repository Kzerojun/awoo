# Apache Kafka 정리

## 1. Kafka란?
- 분산 메시지 브로커 시스템으로, 대량의 데이터를 빠르고 안정적으로 처리할 수 있도록 설계됨.
- **Pub-Sub (Publish-Subscribe) 모델** 기반으로 동작하여, 데이터 스트리밍 및 로그 처리에 많이 사용됨.
- LinkedIn에서 개발되었으며, 현재 Apache Software Foundation에서 관리함.

## 2. Kafka의 주요 특징
### 2.1 분산 시스템
- 클러스터로 구성되어 장애에 강하고 확장성이 뛰어남.
- 브로커(Broker)가 여러 개로 구성되어 데이터 부하를 분산 처리 가능.

### 2.2 높은 처리량과 낮은 지연 시간
- 배치 처리 및 압축을 통해 고속 데이터 전송 지원.
- 로그 기반 저장 방식으로 디스크 I/O를 최소화.

### 2.3 영속성 및 내결함성
- 데이터를 디스크에 저장하여 장애 발생 시에도 손실을 방지.
- 복제(Replication)를 통해 데이터 유실 가능성을 줄임.

### 2.4 확장성
- **파티션(Partition)** 개수를 조정하여 여러 컨슈머(Consumer) 그룹이 병렬로 처리 가능.
- 브로커와 컨슈머를 쉽게 추가하여 확장 가능.

### 2.5 다양한 프로토콜 지원
- HTTP, TCP, WebSocket 등 다양한 프로토콜을 통해 데이터 송수신 가능.


## 3. Kafka의 주요 개념

| 개념 | 설명 |
|------|------------------------------------------|
| **Producer** | 메시지를 생성하여 특정 토픽(Topic)으로 전송 |
| **Consumer** | 특정 토픽의 메시지를 구독(Consume) |
| **Broker** | 데이터를 저장하고 Producer와 Consumer 간의 통신을 중개 |
| **Topic** | 메시지를 구분하는 논리적인 단위 |
| **Partition** | 하나의 Topic을 여러 개의 청크(Partition)로 분할 |
| **Consumer Group** | 여러 개의 Consumer가 동일한 Topic을 병렬로 처리할 수 있도록 그룹화 |

## 4. Kafka의 동작 방식
1. **Producer**가 특정 **Topic**에 메시지를 전송.
2. **Kafka Broker**가 메시지를 수신하고, 해당 **Topic의 Partition**에 저장.
3. **Consumer**가 특정 **Topic**을 구독하여 메시지를 가져감.
4. **Consumer Group**이 설정되어 있으면, 각 Consumer는 서로 다른 Partition을 처리하여 병렬 처리가 가능.


## 5. Kafka의 사용 사례
- **로그 수집 및 분석**  
  - 대량의 애플리케이션 로그를 실시간으로 수집하고 분석 가능.
  
- **실시간 데이터 스트리밍**  
  - 금융 거래, IoT 센서 데이터, 소셜 미디어 스트리밍 등의 실시간 데이터 처리.

- **이벤트 기반 시스템**  
  - 주문 처리, 결제 시스템 등 이벤트 기반의 비동기 처리.

- **메시지 큐 역할**  
  - RabbitMQ, ActiveMQ 같은 메시지 큐와 유사한 역할 수행 가능.

## 6. Kafka와 다른 메시지 큐 시스템 비교

| 특징 | Kafka | RabbitMQ |
|------|----------------------|----------------|
| **설계 철학** | 분산 로그 저장 및 스트리밍 | 메시지 브로커 |
| **메시지 보관 기간** | 기본적으로 무제한(로그 기반) | 메시지 소비 후 삭제 |
| **처리 방식** | 대량의 데이터 스트리밍에 최적화 | 빠른 응답을 요구하는 메시지 전달에 적합 |
| **사용 사례** | 데이터 파이프라인, 로그 수집 | 요청-응답 기반의 메시지 처리 |

## 7. Spring Boot에서 Kafka 사용 예제
### 7.1 의존성 추가 (`build.gradle`)
```gradle
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter'
    implementation 'org.springframework.kafka:spring-kafka'
}
```

### 7.2 Producer 구현
```gradle
@Service
public class KafkaProducer {
    private static final String TOPIC = "test-topic";

    private final KafkaTemplate<String, String> kafkaTemplate;

    public KafkaProducer(KafkaTemplate<String, String> kafkaTemplate) {
        this.kafkaTemplate = kafkaTemplate;
    }

    public void sendMessage(String message) {
        kafkaTemplate.send(TOPIC, message);
    }
}

```


### 7.3 Consumer 구현
```gradle
@Service
public class KafkaConsumer {
    @KafkaListener(topics = "test-topic", groupId = "my-group")
    public void consume(String message) {
        System.out.println("Received message: " + message);
    }
}
```


### 7.4 설정 파일 (application.yml)
```gradle
spring:
  kafka:
    bootstrap-servers: localhost:9092
    consumer:
      group-id: my-group
      auto-offset-reset: earliest

```

## 결론

- Kafka는 분산 메시지 브로커로, 대량의 데이터 스트리밍과 로그 처리에 최적화된 시스템.

- 확장성과 내결함성이 뛰어나며, 실시간 데이터 파이프라인 구축에 적합.

- Spring Boot와의 연동이 용이하여 다양한 애플리케이션에서 활용 가능.
