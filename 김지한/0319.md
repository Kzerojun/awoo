# extends

## Java `extends` 키워드

`extends` 키워드는 자바에서 클래스나 인터페이스가 다른 클래스를 상속하거나, 인터페이스가 다른 인터페이스를 확장할 때 사용됩니다. 이를 통해 상속받은 클래스는 부모 클래스의 메서드와 필드를 사용할 수 있게 됩니다.

### 1. 클래스 상속

클래스가 다른 클래스를 상속할 때 `extends`를 사용합니다. 상속받은 클래스는 부모 클래스의 메서드와 필드를 상속받으며, 부모 클래스의 메서드를 오버라이드하여 재정의할 수 있습니다.

#### 사용법

```java
class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}
```

### 2.인터페이스 확장

인터페이스가 다른 인터페이스를 확장할 때도 extends를 사용합니다. 확장된 인터페이스는 부모 인터페이스의 메서드를 모두 상속받고, 이를 구현하는 클래스는 부모 인터페이스의 메서드를 구현해야 합니다.

### 3. 특징

- 클래스 상속: 상속받은 클래스는 부모 클래스의 속성(필드)과 기능(메서드)을 물려받습니다.

- 인터페이스 확장: 인터페이스는 다른 인터페이스를 확장하여 더 많은 기능을 정의할 수 있습니다.

- 다중 상속은 인터페이스에서만 가능하고, 클래스에서는 한 클래스만 상속받을 수 있습니다.
