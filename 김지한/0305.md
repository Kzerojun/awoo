# 0305 TIL

## Lombok
Lombok은 Java에서 반복적인 코드(boilerplate code)를 자동으로 생성해 주는 라이브러리

- Getter, Setter, 생성자, toString(), equals(), hashCode() 등을 자동으로 생성

- 빌더 패턴, 로그(logging) 등 다양한 기능 지원

- 코드의 가독성을 높이고 유지보수를 쉽게 할 수 있음

## Lombok 주요 Annotatio

### @Data

- @Getter, @Setter, @ToString, @EqualsAndHashCode, @RequiredArgsConstructor를 포함하는 종합 패키지 어노테이션

- 모든 필드의 Getter/Setter, toString(), equals(), hashCode() 메서드가 자동 생성됨

- final이 아닌 필드는 setter도 자동 생성됨

- 주의 사항

    -  @Data는 모든 필드에 대해 Setter가 생성되므로, JPA 엔티티에서 사용 시 불변성이 깨질 수 있음  

        => @Getter + @Setter + @ToString 등을 개별적으로 사용하는 것이 좋음.

### @Builder

- 빌더 패턴을 적용하여 객체를 생성할 수 있도록 함

- @AllArgsConstructor가 필요함

### @AllArgsConstructor

- 모든 필드를 매개변수로 받는 생성자를 자동 생성

### @NoArgsConstructor

- 기본 생성자(매개변수가 없는 생성자) 를 자동 생성

- *JPA* 엔티티를 만들 때 *필수*로 사용됨


## Lombok Annotatio 정리


| 어노테이션              | 역할                                                         |
|------------------------|------------------------------------------------------------|
| `@Data`               | `Getter`, `Setter`, `toString()`, `equals()`, `hashCode()` 포함 |
| `@Getter`             | Getter 메서드 자동 생성                                      |
| `@Setter`             | Setter 메서드 자동 생성                                      |
| `@NoArgsConstructor`  | 기본 생성자 자동 생성                                       |
| `@AllArgsConstructor` | 모든 필드를 매개변수로 받는 생성자 생성                     |
| `@RequiredArgsConstructor` | `final` 또는 `@NonNull` 필드만 포함한 생성자 생성        |
| `@Builder`            | 빌더 패턴 적용                                              |
| `@ToString`          | `toString()` 자동 생성                                      |
| `@EqualsAndHashCode`  | `equals()` 및 `hashCode()` 자동 생성                        |
| `@Slf4j`             | `Logger` 객체 자동 생성                                     |
