## 쓰레드(Thread)

### 1. **정의**
쓰레드는 프로세스 내에서 실행되는 기본적인 작업 단위입니다. 프로세스는 하나 이상의 쓰레드를 포함할 수 있으며, 각 쓰레드는 독립적인 실행 흐름을 가집니다. 쓰레드를 사용하면 동시에 여러 작업을 처리할 수 있어 성능 향상과 자원 효율성을 높일 수 있습니다.

### 2. **특징**
- **병렬 실행**: 여러 쓰레드를 사용하면 CPU의 멀티코어를 활용하여 병렬로 작업을 처리할 수 있습니다.
- **경량화**: 쓰레드는 프로세스에 비해 생성과 관리가 더 가벼운 단위입니다.
- **공유 자원**: 같은 프로세스 내에서 실행되므로, 쓰레드는 메모리 및 자원을 공유합니다. 이로 인해 데이터 공유와 통신이 용이합니다.

### 3. **쓰레드의 종류**
- **주 쓰레드(Main Thread)**: 프로그램이 시작될 때 기본적으로 실행되는 쓰레드로, UI 스레드나 메인 로직을 담당합니다.
- **서브 쓰레드**: 주 쓰레드 외에 추가적으로 생성되어 실행되는 쓰레드로, 백그라운드 작업이나 병렬 작업을 처리합니다.

### 4. **쓰레드 생성 방법**
- **`Thread` 클래스 사용**: `Thread` 클래스를 상속받거나, `Runnable` 인터페이스를 구현하여 쓰레드를 생성하고 실행할 수 있습니다.
- **`ExecutorService` 사용**: Java의 `ExecutorService`를 통해 쓰레드를 풀(Pool)로 관리하고 효율적으로 쓰레드를 관리할 수 있습니다.

### 5. **동기화(Synchronization)**
쓰레드가 공유 자원에 동시에 접근할 때, 데이터 손상이나 예기치 않은 결과가 발생할 수 있습니다. 이를 방지하기 위해 **동기화**를 사용하여 하나의 쓰레드만 자원에 접근할 수 있도록 합니다.
- **`synchronized` 키워드**: 특정 메서드나 블록에 대해 동기화를 적용하여 하나의 쓰레드만 해당 부분을 실행하도록 제한합니다.

### 6. **문제점**
- **데드락(Deadlock)**: 두 개 이상의 쓰레드가 서로 자원을 기다리며 무한 대기 상태에 빠지는 문제입니다.
- **경합 상태(Race Condition)**: 여러 쓰레드가 동시에 동일한 자원을 변경할 때 예기치 않은 동작이 발생할 수 있습니다.
- **쓰레드 안전성**: 멀티 쓰레드 환경에서 데이터의 일관성을 유지하기 위한 방법으로, `Atomic` 클래스나 `Concurrent` 패키지를 활용할 수 있습니다.

### 7. **쓰레드 관리**
- **쓰레드 풀(Thread Pool)**: 쓰레드 풀을 사용하여 쓰레드를 재사용하고, 불필요한 쓰레드 생성을 방지할 수 있습니다. Java에서는 `ExecutorService`와 같은 API로 쓰레드 풀을 관리할 수 있습니다.

### 8. **사용 사례**
- **병렬 처리**: 대용량 데이터 처리나 복잡한 계산을 여러 쓰레드를 사용해 병렬로 처리하여 성능을 최적화할 수 있습니다.
- **비동기 작업**: UI에서 사용자 입력을 처리하면서, 백그라운드에서 데이터를 로드하거나 계산하는 등의 비동기 작업을 처리할 때 쓰레드를 사용합니다.

쓰레드는 멀티 태스킹과 성능 최적화를 위한 강력한 도구지만, 적절한 동기화와 관리가 필요하여, 잘못 사용하면 성능 저하나 오류를 초래할 수 있습니다.
