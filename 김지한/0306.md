# **우선순위 큐 (Priority Queue)**

## **1. 개념**
- **우선순위(priority)**를 기준으로 요소를 정렬하여 **가장 높은(혹은 낮은) 우선순위를 가진 요소를 먼저 처리**하는 자료구조.
- 일반적인 **큐(Queue)는 FIFO(First In First Out) 방식**이지만, 우선순위 큐는 **우선순위가 높은 요소가 먼저 처리됨**.

---

## **2. 주요 특징**
| 특징 | 설명 |
|------|------|
| **정렬 기준** | 요소의 우선순위를 기준으로 정렬됨 |
| **삽입 연산** | O(log N) (힙 사용 시) |
| **삭제 연산** | O(log N) (최대/최소값 삭제) |
| **탐색 연산** | O(1) (최대/최소값 확인) |
| **구현 방식** | 힙(Heap) 또는 정렬된 배열/리스트 사용 |

---

## **3. 우선순위 큐의 구현 방식**
| 구현 방식 | 시간 복잡도 | 설명 |
|----------|------------|------|
| **정렬된 배열** | 삽입: O(N), 삭제: O(1) | 정렬된 상태 유지하지만 삽입이 느림 |
| **정렬된 연결 리스트** | 삽입: O(N), 삭제: O(1) | 배열과 유사하지만 메모리 효율적 |
| **정렬되지 않은 배열** | 삽입: O(1), 삭제: O(N) | 삽입은 빠르지만 최댓값/최솟값 찾기가 느림 |
| **힙(Heap) 사용** | 삽입: O(log N), 삭제: O(log N) | **가장 효율적**, 대부분의 경우 사용 |

---

## **4. 자바에서 우선순위 큐 사용**
### **(1) 기본적인 `PriorityQueue` 사용법**
```java
import java.util.PriorityQueue;

public class Main {
    public static void main(String[] args) {
        PriorityQueue<Integer> pq = new PriorityQueue<>(); // 기본: 최소 힙

        pq.offer(5);
        pq.offer(2);
        pq.offer(8);
        pq.offer(1);

        while (!pq.isEmpty()) {
            System.out.println(pq.poll()); // 1 → 2 → 5 → 8 (오름차순)
        }
    }
}
