# Spring Bean 

스프링에서 **빈(Bean)**은 스프링 컨테이너에 의해 관리되는 객체를 의미합니다. 스프링은 객체 생성, 의존성 주입, 생명 주기 관리 등을 컨테이너에서 처리하며, 개발자는 객체의 생성과 관리를 스프링에 맡깁니다. 스프링 빈은 **스프링의 핵심** 개념 중 하나입니다.

## 1. Spring Bean 정의

스프링 빈은 `@Component`, `@Service`, `@Repository`, `@Controller`와 같은 어노테이션을 사용하여 정의할 수 있습니다. 이 어노테이션은 모두 `@Component`의 특수화된 형태로, 해당 클래스가 스프링 컨테이너에서 관리되어야 함을 나타냅니다.

#### 예시:

```java
@Component
public class MyService {
    public void performTask() {
        System.out.println("Task performed!");
    }
}

```

## 2. 스프링 빈의 생성 및 관리

스프링 컨테이너는 애플리케이션 컨텍스트를 통해 빈을 관리합니다. 빈은 애플리케이션 시작 시 초기화되고, 필요에 따라 주입됩니다. 빈은 주로 **의존성 주입(DI)**을 통해 다른 객체와 연결됩니다.

#### 예시:

```java
@Component
public class MyController {
    
    @Autowired
    private MyService myService;

    public void handleRequest() {
        myService.performTask();
    }
}

```


## 3. 빈의 생명주기

스프링 빈은 여러 가지 생명주기 메서드를 가질 수 있습니다. 빈의 초기화, 종료 등을 설정할 수 있습니다.

- @PostConstruct: 빈 초기화 후 호출

- @PreDestroy: 빈 종료 전 호출

- init-method, destroy-method: XML 설정에서 사용할 수 있는 초기화 및 종료 메서드


#### 예시:

```java
@Component
public class MyService {

    @PostConstruct
    public void init() {
        System.out.println("빈 초기화");
    }

    @PreDestroy
    public void destroy() {
        System.out.println("빈 종료");
    }
}

```


## 4. 빈의 스코프 (Scope)

빈은 스코프를 설정하여 빈의 생명주기를 제어할 수 있습니다. 스프링에서 제공하는 기본 빈 스코프는 다음과 같습니다:

- singleton: 기본값, 스프링 컨테이너에서 단 하나의 인스턴스를 공유.

- prototype: 빈을 요청할 때마다 새로운 인스턴스가 생성.

- request: HTTP 요청당 하나의 빈 인스턴스를 생성.

- session: HTTP 세션당 하나의 빈 인스턴스를 생성.

- application: 웹 애플리케이션당 하나의 빈 인스턴스를 생성.


#### 예시:

```java
@Component
@Scope("prototype")
public class MyPrototypeBean {
    // 프로토타입 빈 설정
}


```


## 5. 빈의 의존성 주입 (DI)
스프링은 의존성 주입을 통해 빈 간의 관계를 설정합니다. 의존성 주입은 생성자 주입, 필드 주입, 세터 주입 방식으로 이루어질 수 있습니다.

## 6. 빈의 자동 주입 (Autowiring)
스프링은 @Autowired 어노테이션을 통해 자동으로 의존성 주입을 수행할 수 있습니다. @Autowired는 생성자, 필드, 세터에 사용할 수 있습니다.

## 7. 빈의 이름 지정
빈의 이름은 기본적으로 클래스 이름을 사용하지만, @Component 어노테이션에 value 속성을 사용하여 이름을 지정할 수 있습니다.

## 8. @Configuration과 @Bean
스프링에서는 자바 기반 설정을 통해 빈을 등록할 수 있습니다. @Configuration 클래스에서 @Bean 메서드를 사용하여 빈을 정의할 수 있습니다.


## 요약
스프링 빈은 스프링 컨테이너에서 관리되는 객체입니다.

- @Component, @Service, @Repository, @Controller 어노테이션을 사용하여 빈을 정의할 수 있습니다.

- 스프링 빈은 **의존성 주입(DI)**을 통해 다른 빈을 주입받을 수 있습니다.

- 빈의 생명주기는 초기화, 종료 메서드를 통해 관리할 수 있습니다.

- 빈의 스코프는 singleton, prototype 등으로 설정할 수 있습니다.

- 자동 주입을 통해 스프링은 빈 간의 의존성을 자동으로 해결합니다.
